# PimSaduak

PimSaduak is a browser-based parcel label printer built with React. Label data stays in the browser; the app does not use a server or API.

## Development

```bash
npm install
npm run dev
```

## Current scope

Step 1 provides a single-label form, a live 10 × 15 cm preview, and browser printing. See [PLAN.md](PLAN.md) for the implementation sequence.
